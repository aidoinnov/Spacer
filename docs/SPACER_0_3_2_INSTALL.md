# Spacer 0.3.2 — installed 2026-11-25

Spacer 0.3.2 is installed and running on the Mac and Windows 132. Both use
optimized production builds and the retained 184-byte node model. The 168-byte
candidate is preserved as a patch under `docs/pending/`; normal builds no longer
include it.

## Changes

Root-folder totals now update with the same observed bytes as scan progress.
The Mac adapter sends the bounded folder candidates without cutting them to four.
The builder tracks changed root branches, so a heartbeat does not revisit every
previously discovered root folder. Logical and allocated rankings are independent.
The remaining tile describes observed items omitted from the map, rather than
calling those bytes unfinished analysis.

Installation checks also found and fixed two integration issues:

- Navigation now resolves native path aliases when the supplied spelling falls
  outside the current lexical scope. This covers Windows short user-profile
  paths while preserving cached/offline snapshot paths.
- The default controller namespace comes from `product.json`. Explicit QA
  overrides remain supported. A manual release build no longer silently uses
  the old `.gpui` controller namespace.

`--background` opens the production window without requesting activation.
The installation checks used that option and sent no mouse or keyboard input.

## Installer and rollback

The DMG was mounted read-only and its payload matched the installed bundle and
manifest. Strict deep signature verification passed after real MCP use, and the
bundled MCP directory remained 0555 without generated bytecode.

The Windows EXE was installed and uninstalled in an owned smoke directory. An
unknown sentinel survived removal. The same installer then installed 0.3.2 to
its final location. Installed payload hashes were checked against the package.

The previous Mac app was verified against its historical archive before removal.
The Windows app's existing analysis was saved as SNS before closing it. Its full
installed directory was ZIP-archived and byte-verified before the old managed
installation and shortcuts were removed. User settings and recovery locations
remain compatible.
